# Brick Breaker Ball

[العربية](README_AR.md)

Brick Breaker Ball is a portrait Android game built with Kotlin and LibGDX. In Volley mode, aim and launch balls, clear descending bricks, collect power-ups, and progress through nine themed worlds.

The Android project source is under [`app/src/main`](app/src/main). Open the project in Android Studio to work on the game.
