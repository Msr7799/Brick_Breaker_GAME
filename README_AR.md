# Brick Breaker Ball

[English](README.md)

Brick Breaker Ball لعبة كسر طوب عمودية لأجهزة Android، مطوّرة باستخدام Kotlin وLibGDX. في طور Volley تصوّب الكرات وتطلقها، وتكسر الطوب الهابط، وتجمع عناصر القوة، وتتقدم عبر تسعة عوالم.

كود مشروع Android موجود في [`app/src/main`](app/src/main). افتح المشروع في Android Studio للعمل على اللعبة.
